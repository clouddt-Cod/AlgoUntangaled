See Inside the Algorithm

Step through Bubble Sort, Merge Sort, Binary Search, BFS, and DFS with live pseudocode, call stack inspection, rainbow-mapped bars, and real-time complexity charts.

Built for Understanding, Not Just Watching

Each algorithm gets a visualization designed around its unique behavior.

🌈

Rainbow-Mapped Bars

Bars colored by final sorted position. Shuffled = rainbow static. Sorted = smooth gradient. A second ambient signal of "how sorted" the array is.

📍

Scatter Plot for Binary Search

Dots at X=index, Y=value. Sorted array = diagonal line. Visually explains why binary search requires sorted input in a way bars cannot.

🌐

Node Graph for BFS & DFS

BFS = yellow in-queue vs green processed rings. DFS = glowing thread that backtracks on dead ends. Same graph, different data structure behavior.
